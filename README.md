# nomercy3d release site

Public GitHub Pages site for nomercy3d releases. The game's source lives in a
separate repository.

- `index.html` is the page.
- `img/` holds the class portraits.
- Drop a `gameplay.mp4` next to `index.html` and the page embeds it automatically.
- Release assets (APK, video) are attached to the GitHub Release for each tag.
